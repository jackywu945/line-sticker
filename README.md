# LINE 貼圖裁剪／製作工具

網址：https://jackywu945.github.io/line-sticker/ （動態貼圖）
靜態貼圖：https://jackywu945.github.io/line-sticker/static.html

- 純網頁工具，圖片都在自己的瀏覽器處理，不會上傳。
- 動態版：上傳 GPT 畫的九宮格 → 切割 → 自動校正晃動（位置＋角度＋大小）→ 匯出 APNG／整組貼圖 ZIP。
- 自動校正晃動：每格對準第一格，比對時自動忽略揮動的手等動作部位。重新校正會清除逐格筆刷修改，請先校正再用橡皮擦修。
- 來回播放：勾選後自動排成 1→…→最後→…→2，揮手這類動作循環才不會跳。
- 封面／從第幾格開始播：指定的那格會變成 LINE 的封面（第一格），動作順序不會被打亂。
- 檔案超過 1 MB 時會自動減色壓縮（只降顏色精度，透明度不動）。
